# COVID-19 Global Impact Dashboard

## Project Overview
The COVID-19 Global Impact Dashboard is a data analytics project that analyzes the worldwide impact of the COVID-19 pandemic. It focuses on understanding COVID-19 cases, deaths, vaccination progress and trends across different countries.

The project uses Python for data cleaning and analysis and Power BI for creating interactive visualizations.

## Objectives
- Analyze worldwide COVID-19 cases and deaths.
- Compare COVID-19 impact across different countries.
- Analyze vaccination progress.
- Identify trends using time-series analysis.
- Calculate 7-day rolling averages and case fatality rates.
- Develop an interactive Power BI dashboard.

## Dataset
**Source:** Our World in Data

Dataset Link: https://ourworldindata.org/coronavirus

The dataset contains country-wise and date-wise COVID-19 information, including cases, deaths, population and vaccination statistics.

## Data Cleaning and Preprocessing
- Loaded the COVID-19 dataset using Pandas.
- Handled missing values.
- Converted date columns into datetime format.
- Sorted records by country and date.
- Selected relevant columns.
- Calculated 7-day average cases.
- Calculated case fatality rate.

## Data Analysis and Visualizations
The project includes:
1. Top 10 countries by COVID-19 cases.
2. Top 10 countries by COVID-19 deaths.
3. Monthly COVID-19 case trends.
4. Country-wise vaccination progress.
5. Case fatality rate comparison.
6. Interactive Power BI dashboard.
